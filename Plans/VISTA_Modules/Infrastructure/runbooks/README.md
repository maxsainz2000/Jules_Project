# VISTA Infrastructure Runbooks

This directory contains operational runbooks for deploying, maintaining, and recovering the VISTA MerchSys platform.

## Quick Reference Table

| Runbook | Description | Role |
| :--- | :--- | :--- |
| [01-production-deployment.md](01-production-deployment.md) | Standard deployment guide. | Admin / Operator |
| [01-host-laptop-setup.md](01-host-laptop-setup.md) | Initial setup for the host laptop (server) running MariaDB and VISTA. | Admin |
| [02-client-laptop-setup.md](02-client-laptop-setup.md) | Initial setup for the client laptop running VISTA connecting to the host. | Admin / Operator |
| [03-nightly-backup.md](03-nightly-backup.md) | Setup and management of the automated nightly backup scripts. | Admin |

*Note: Runbooks should be executed sequentially when setting up a new site.*
